# ELRAID Company Website

## Overview

ELRAID Company Website is a simple and modern web page designed for a company that sells high-quality nuts and dried fruits.
The website presents the company's products, services, and contact information in a clean and user-friendly layout.

This project was created as a front-end web project using basic web technologies.

---

## Features

* Modern and responsive design
* Product presentation section
* Company information
* Clean and simple user interface
* Easy navigation

---

## Technologies Used

* HTML5
* CSS3
* JavaScript

---

## Project Structure

```
ELRAID_Company
│
├── index.html
├── style.css
└── script.js
```

* **index.html** → Main webpage structure
* **style.css** → Website styling and layout
* **script.js** → Interactive functionality

---

## Purpose of the Project

This project was built to represent a company that specializes in selling different types of nuts such as almonds, walnuts, pistachios, and more.

The goal of the website is to provide customers with a simple way to learn about the company and its products.
